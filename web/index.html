A skill for Claude Code

End a session. Resume it cold, without re-reading everything.

Session Handoff turns the end of your work into a small, pointer-first document: what's done, what's half-done, where the files live, and the one next action. The next session, tomorrow or fresh after /clear, picks up exactly where you stopped, for a fraction of the tokens.

Install the skill View on GitHub free · MIT · works with any task
What it does

A routing artifact, not a status report.

The handoff is written for the next instance of the model, not for a stakeholder. It links to your source files instead of pasting them, so resuming means reading one screen, then pulling only the file the current step needs.

Step ledger

Done, in-progress, and pending items: the one thing your plan files don't already contain. The resume anchor.

Pointer-first

Links to the brainstorm, plan, and deliverables; never copies them. The whole point is token efficiency.

Parallel tracks

Fan one finished plan out into several sessions. Each track owns disjoint files, so they never clobber each other.

The difference

Doing it without the skill vs. with it.

Continuing a long task across sessions normally forces a bad trade: re-paste everything (slow, expensive) or wing it from memory (lossy). The skill removes the trade.

Without Manual handoff

  • Re-paste the transcript or re-explain from scratch
  • High token cost: full context re-sent every time
  • "What's done?" is fuzzy, recalled from memory
  • Decisions get re-derived; finished files get re-read
  • Parallel sessions step on each other's files
  • You open the new session asking "where was I?"

With Session Handoff

  • Next session reads one short file
  • Low token cost: links, not copies
  • Explicit step ledger: done / half-done / pending
  • Source material is referenced, pulled only when needed
  • Fan-out tracks own disjoint files, no collisions
  • One explicit "pick up here" line waiting for you
Install

A skill is just a folder with a SKILL.md.

Drop it where Claude Code looks for skills, restart, and it activates on its own when you say "session handoff" or "wrap up this session." No slash command.

# clone and install into your Claude Code skills directory git clone https://github.com/hackeryisus/claude-session-handoff mkdir -p ~/.claude/skills/session-handoff cp claude-session-handoff/skill/SKILL.md ~/.claude/skills/session-handoff/SKILL.md # or just tell Claude Code: "Clone hackeryisus/claude-session-handoff and install the skill for me."

Chat mode default

Say wrap up this session. Prints the handoff right in the conversation: a quick "where am I" before you clear.

File mode

Say handoff to file. Writes a portable *-handoff.md a fresh session resumes from, or splits into parallel tracks.
